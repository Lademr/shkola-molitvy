# 🛠️ Админ-панель Школы Молитвы

## 📋 Обзор

Полноценная панель управления для администратора сайта с возможностью:
- Просмотра статистики и аналитики
- Управления учениками и их прогрессом
- Работы с сообщениями и обратной связью
- Экспорта данных для резервного копирования

---

## 🔐 Доступ к админ-панели

### URL для входа:
```
http://localhost:5173/#/admin
```

### Пароль по умолчанию:
```
admin123
```

### Как изменить пароль:
Откройте файл `src/contexts/AdminContext.tsx` и измените строку:
```typescript
const ADMIN_PASSWORD = 'admin123'; // ← Измените на свой пароль
```

## 📊 Разделы админ-панели

### 1. Дашборд (`/admin/dashboard`)
Главная страница с общей статистикой:

**Карточки статистики:**
- 👥 Всего учеников
- 📖 Уроков пройдено
- 💬 Сообщений
- 📈 Средний прогресс

**Графики:**
- Прогресс по урокам (столбчатая диаграмма)
- Активность учеников (круговая диаграмма)

**Топ ученики:**
- Список 5 самых активных учеников
- Количество пройденных уроков
- Количество записей в дневнике

**Последние сообщения:**
- 5 последних сообщений с сайта
- Быстрый доступ к полной ленте

**Экспорт данных:**
- Кнопка для скачивания всех данных в JSON
- Полезно для резервного копирования

---

### 2. Ученики (`/admin/students`)
Полный список всех зарегистрированных учеников:

**Функции:**
- 🔍 Поиск по имени или email
- 📊 Детальная карточка каждого ученика:
  - Имя и email
  - Дата регистрации
  - Процент прогресса
  - Количество пройденных уроков
  - Количество записей в дневнике
  - Количество сертификатов
  - Серия молитв (streak)

**Пример карточки ученика:**
```
👤 Мария К.
   maria@example.com
   Регистрация: 15.01.2024
   
   Прогресс: 100%
   
   📖 Уроки: 2/2
   📝 Дневник: 15 записей
   🏆 Сертификаты: 2
   
   🔥 Серия молитв: 7 дней
```

---

### 3. Сообщения (`/admin/messages`)
Управление всеми сообщениями от учеников:

**Фильтры:**
- Все сообщения
- Обратная связь (форма контактов)
- Сообщество (посты на форуме)

**Функции:**
- 💬 Просмотр всех сообщений
- ✍️ Ответы на сообщения
- ✅ Отметка отвеченных сообщений
- 🔄 Изменение ответов

**Пример работы с сообщением:**
1. Открываете список сообщений
2. Выбираете нужное сообщение
3. Нажимаете "Ответить"
4. Вводите текст ответа
5. Нажимаете "Отправить ответ"
6. Ответ сохраняется и отображается в сообщении

## 📥 Экспорт данных

### Зачем нужен экспорт?
- Резервное копирование всех данных
- Перенос данных между устройствами
- Анализ данных в Excel/Google Sheets
- Архивирование информации

### Как экспортировать:
1. Перейдите в **Дашборд**
2. Нажмите кнопку **"Экспорт данных"**
3. Файл `shkola-molitvy-backup-YYYY-MM-DD.json` скачается автоматически

### Структура экспортируемых данных:
```json
{
  "students": [
    {
      "name": "Мария К.",
      "email": "maria@example.com",
      "joinDate": "2024-01-15T10:30:00.000Z",
      "completedLessons": [1, 2],
      "quizScores": {"1": 100, "2": 75},
      "diaryEntries": [...],
      "prayerStreak": 7,
      "certificates": [...]
    }
  ],
  "feedbackMessages": [...],
  "forumPosts": [...],
  "exportDate": "2024-01-28T15:45:00.000Z"
}
```

## 🔧 Технические детали

### Хранение данных
Все данные хранятся в **localStorage** браузера:
- `user_<email>` — данные каждого ученика
- `feedbackMessages` — сообщения из формы обратной связи
- `forumPosts` — посты из раздела "Сообщество"
- `isAdmin` — статус авторизации администратора

### Ограничения текущей версии
⚠️ **Важно:** Поскольку данные хранятся в localStorage каждого браузера отдельно:
- Админ видит только данные того браузера, где он авторизован
- Для синхронизации данных между устройствами используйте экспорт/импорт
- В будущем планируется интеграция с Firebase/Supabase для централизованного хранения

### Безопасность
⚠️ **Текущая защита:**
- Простая проверка пароля на клиенте
- Подходит для демо и внутреннего использования

🔒 **Для продакшена рекомендуется:**
- Серверная авторизация (JWT токены)
- HTTPS протокол
- Rate limiting для защиты от брутфорса
- Двухфакторная аутентификация
