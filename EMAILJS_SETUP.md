## 🚀 Пошаговая инструкция по настройке EmailJS

### Шаг 1: Регистрация на EmailJS

1. Перейдите на сайт **[https://www.emailjs.com/](https://www.emailjs.com/)**
2. Нажмите **"Sign Up"** (Регистрация)
3. Зарегистрируйтесь через email или Google аккаунт
4. Подтвердите email (придет письмо с подтверждением)

---

### Шаг 2: Добавление Email Service

1. После входа перейдите в раздел **"Email Services"** (левое меню)
2. Нажмите **"Add New Service"**
3. Выберите **"Gmail"** (так как ваш email eksinss@gmail.com)
4. Нажмите **"Connect Account"**
5. Войдите в ваш аккаунт Gmail и разрешите доступ
6. После подключения вы увидите страницу с параметрами:
   - **Service ID** — скопируйте его (например: `service_abc123xyz`)
   - **Service Name** — можно оставить по умолчанию

7. Нажмите **"Create Service"**

---

### Шаг 3: Создание Email Template

1. Перейдите в раздел **"Email Templates"** (левое меню)
2. Нажмите **"Create New Template"**
3. Заполните поля:

#### Вкладка "Content":

**Subject (Тема письма):**
```
Новое сообщение от {{from_name}} - Школа Молитвы
```

**To email (Кому):**
```
{{to_email}}
```

**From name (От кого):**
```
Школа Молитвы - {{from_name}}
```

**Reply to (Ответить на):**
```
{{reply_to}}
```

**Content (Содержимое письма):**
```html
<h2>Новое сообщение с сайта Школы Молитвы</h2>

<p><strong>От:</strong> {{from_name}}</p>
<p><strong>Email:</strong> {{reply_to}}</p>
<p><strong>Дата:</strong> {{date}}</p>

<hr>

<h3>Сообщение:</h3>
<p>{{message}}</p>

<hr>

<p style="color: #666; font-size: 12px;">
  Это автоматическое письмо с сайта shkola-molitvy.ru<br>
  Вы можете ответить на это письмо, и ответ придет ученику.
</p>
```

4. Нажмите **"Save"** (сохранить)

5. После сохранения вы увидите:
   - **Template ID** — скопируйте его (например: `template_xyz789abc`)

---

### Шаг 4: Получение Public Key

1. Перейдите в раздел **"Account"** (левое меню)
2. Прокрутите вниз до секции **"API Keys"**
3. Скопируйте **Public Key** (например: `abcDEF123ghiJKL456`)

⚠️ **Важно:** Используйте только Public Key, никогда не публикуйте Private Key!

## 🎁 Бонус: Настройка автоответа ученику (опционально)

Если хотите, чтобы ученики получали автоматическое подтверждение:

1. Создайте **второй Email Template** на EmailJS:
   - **Subject:** `Спасибо за ваше сообщение! Школа Молитвы`
   - **To email:** `{{to_email}}`
   - **Content:**
   ```html
   <h2>Здравствуйте, {{to_name}}!</h2>
   
   <p>Спасибо за ваше сообщение в Школу Молитвы.</p>
   <p>Мы получили его и ответим в ближайшее время.</p>
   
   <p>Благословений вам в молитвенной жизни!</p>
   
   <p>С любовью,<br>Команда Школы Молитвы<br>shkola-molitvy.ru</p>
   ```

2. Скопируйте **Template ID** этого шаблона

3. В файле `src/config/emailjs.ts` найдите функцию `sendAutoReply` и замените:
   ```typescript
   'YOUR_AUTO_REPLY_TEMPLATE_ID'
   ```
   на ваш Template ID автоответа

4. В `FeedbackPage.tsx` добавьте вызов автоответа после успешной отправки:
   ```typescript
   // После успешной отправки администратору
   if (email) {
     await sendAutoReply({
       to_email: email,
       from_name: name,
     });
   }
   ```

## 🐛 Решение проблем

### Проблема: Письма не приходят
**Решение:**
1. Проверьте, правильно ли указаны все три ключа
2. Убедитесь, что Mail.ru сервис подключен и активен
3. Проверьте папку "Спам" в почте
4. Посмотрите консоль браузера (F12) на наличие ошибок

### Проблема: Ошибка "Service not found"
**Решение:**
- Проверьте Service ID — он должен точно совпадать с тем, что в EmailJS

### Проблема: Ошибка "Template not found"
**Решение:**
- Проверьте Template ID
- Убедитесь, что шаблон сохранен и активен
