## 📖 О проекте

«Школа Молитвы» — это бесплатный интерактивный курс для христиан, направленный на развитие глубокой молитвенной жизни через водительство Святым Духом.

### Что включает курс:

- ✅ **8 уроков** с глубоким разбором Писания
- ✅ **11 статей** в блоге
- ✅ **32 тестовых вопроса** для проверки знаний
- ✅ **32+ разбора** библейских текстов
- ✅ **Молитвенный дневник** для записи молитв и ответов
- ✅ **Сообщество** для общения с другими учениками
- ✅ **Личный кабинет** с отслеживанием прогресса

---

## 🎓 Уроки

### Блок I: Основы духовной молитвы

1. **Единственный Учитель** — переход от автономии разума к водительству Духом
2. **Истинные поклонники** — разделение духа, души и тела
3. **Наедине с Богом** — тишина интуиции против шума чувств
4. **Образец молитвы** — воля Царства против эгоизма души
5. **Несомненный ответ** — закон Царства и интуитивное озарение
6. **Бесконечное отцовство** — Дух сыновства (Рим. 8:15)

### Блок II: Очищение и сила веры

7. **Всеобъемлющий дар** — Святой Дух в глубине духа
8. **Смелость Божьих детей** — сострадание и бодрствование

## 🚀 Технологии

- **Frontend:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router (HashRouter)
- **Icons:** Lucide React
- **Hosting:** GitHub Pages
- **Backend:** PHP 8.1 + MySQL (Beget)
- **Email:** EmailJS

## 📦 Установка и запуск

### Требования

- Node.js 18+
- npm или yarn

### Локальная разработка

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/shkola-molitvy.git
cd shkola-molitvy

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173)

### Сборка для продакшена

```bash
# Собрать проект
npm run build

# Предпросмотр production-версии
npm run preview
```
