## 🎯 Обзор проекта

Школа Молитвы — это бесплатный интерактивный курс для христиан, включающий:

- 📖 **Пошаговые уроки** с глубоким разбором Писания
- 🙏 **Коллекцию молитв** на разные случаи жизни
- 📜 **Разборы текстов Библии** с контекстом и применением
- ✅ **Тесты** для проверки знаний
- 📝 **Молитвенный дневник** для записи молитв и ответов
- 💬 **Сообщество** для общения учеников
- 📝 **Блог** со статьями о молитвенной жизни
- 🎥 **Видеоуроки** (в разработке)
- ⏰ **Напоминания** о молитве
- 🌙 **Тёмная тема** для комфортного использования
- 📊 **Личный кабинет** с отслеживанием прогресса
- 🎁 **Сертификаты** за прохождение уроков

#### 7. 📝 Блог

#### 8. 🎥 Видеоуроки

- Советы по молитвенной дисциплине

#### 10. 📊 Личный кабинет

- Сертификаты за уроки
- Серия молитв (streak)

## 🛠 Технологии

### Frontend
- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **React Router** — маршрутизация (HashRouter для SPA)
- **Tailwind CSS** — стилизация
- **Lucide React** — иконки

### Хранение данных
- **localStorage** — все данные хранятся локально в браузере
- Нет бэкенда — полностью клиентское приложение

### SEO
- Мета-теги (title, description, keywords)
- Open Graph (Facebook, VK, Telegram)
- Twitter Cards
- Structured Data (JSON-LD)
- robots.txt, sitemap.xml
- PWA manifest

## 👤 Руководство пользователя

### Регистрация
1. Нажмите "Войти" в навигации
2. Введите имя и email
3. Данные сохраняются локально в браузере

### Прохождение уроков
1. Перейдите в раздел "Уроки"
2. Выберите урок
3. Изучите материал (вкладки: Обзор, Писание, Разбор, Тест, Задание)
4. Пройдите тест
5. Отметьте урок как пройденный
6. Выполните домашнее задание

### Ведение молитвенного дневника
1. Перейдите в раздел "Дневник"
2. Нажмите "Добавить новую запись"
3. Выберите категорию (Просьба, Благодарность, Поклонение, Исповедание, Ходатайство)
4. Запишите молитву
5. Когда Бог ответит — отметьте и добавьте свидетельство

### Общение в сообществе
1. Перейдите в раздел "Сообщество"
2. Напишите пост (можно указать связанный урок)
3. Лайкайте посты других учеников
4. Отвечайте на вопросы

### Тёмная тема
- Нажмите на иконку луны/солнца в навигации
- Тема сохраняется в localStorage

## 🚀 Развёртывание

### 1. Сборка проекта
```bash
npm run build
```

### 2. Загрузка на хостинг
Загрузите содержимое папки `dist/` на ваш хостинг.

### 3. Настройка домена
- Укажите A-запись для shkola-molitvy.ru на IP хостинга
- Настройте SSL-сертификат (Let's Encrypt)

### 4. Верификация в поисковых системах

**Google Search Console:**
1. Добавьте сайт: https://shkola-molitvy.ru
2. Подтвердите владение
3. Отправьте sitemap: https://shkola-molitvy.ru/sitemap.xml
4. Вставьте код верификации в `<meta name="google-site-verification">`

**Яндекс.Вебмастер:**
1. Добавьте сайт
2. Подтвердите права
3. Вставьте код в `<meta name="yandex-verification">`

### 5. Аналитика

**Google Analytics:**
Добавьте в `index.html` перед `</head>`:
```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

**Яндекс.Метрика:**
```html
<script type="text/javascript">
  (function(m,e,t,r,i,k,a){...})(window, document, "script", "https://mc.yandex.ru/metrika/tag.js", "ym");
  ym(XXXXXXXX, "init", {clickmap:true,trackLinks:true,accurateTrackBounce:true});
</script>
```
