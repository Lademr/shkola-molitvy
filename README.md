## 🚀 Рекомендации по деплою

### 1. **Подключение домена**
```bash
# После покупки домена shkola-molitvy.ru:
1. Настройте DNS-записи у регистратора
2. Укажите A-запись на IP хостинга
3. Настройте SSL-сертификат (Let's Encrypt бесплатно)
```

### 2. **Верификация в поисковых системах**

#### Google Search Console:
1. Перейдите на [search.google.com/search-console](https://search.google.com/search-console)
2. Добавьте ресурс: `https://shkola-molitvy.ru`
3. Подтвердите владение (HTML-файл или DNS-запись)
4. Отправьте sitemap: `https://shkola-molitvy.ru/sitemap.xml`
5. Вставьте код верификации в `<meta name="google-site-verification" content="ВАШ_КОД">`

#### Яндекс.Вебмастер:
1. Перейдите на [webmaster.yandex.ru](https://webmaster.yandex.ru)
2. Добавьте сайт: `https://shkola-molitvy.ru`
3. Подтвердите права (мета-тег или HTML-файл)
4. Вставьте код в `<meta name="yandex-verification" content="ВАШ_КОД">`
5. Отправьте sitemap
