# shkola-molitvy
Цель школы: Помочь христианину выйти за рамки сухой религиозной формальности и независимой опоры на собственный интеллект, чтобы войти в глубокое, непрестанное и живое общение с Богом. Школа учит молиться не только умом, но и духом (1 Кор. 14:15), слышать водительство Святого Духа и видеть плоды духовных изменений в повседневной жизни.
