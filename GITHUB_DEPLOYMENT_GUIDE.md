## 📋 Что вам нужно сделать

### ШАГ 1: Регистрация на GitHub (5 минут)

1. Перейдите на **https://github.com**
2. Нажмите **"Sign up"** (правый верхний угол)
3. Заполните форму:
   - Username: придумайте логин (например, `shkola-molitvy`)
   - Email: ваш email
   - Password: придумайте пароль
4. Подтвердите email (придёт письмо со ссылкой)

---

### ШАГ 2: Создание репозитория (3 минуты)

1. После входа нажмите **"+"** в правом верхнем углу
2. Выберите **"New repository"**
3. Заполните:
   - **Repository name:** `shkola-molitvy`
   - **Description:** `Школа Молитвы — Интерактивное обучение молитвенной жизни`
   - **Public** ✅ (обязательно публичный!)
   - **Add a README file** ❌ (НЕ ставьте галочку — у нас уже есть свой)
4. Нажмите **"Create repository"**

---

### ШАГ 3: Загрузка кода на GitHub (10 минут)

#### Вариант A: Через GitHub Desktop (РЕКОМЕНДУЮ для новичков)

1. **Скачайте GitHub Desktop:**
   - Перейдите на https://desktop.github.com/
   - Нажмите "Download for Windows" (или Mac)
   - Установите программу

2. **Войдите в GitHub Desktop:**
   - Откройте программу
   - Нажмите "Sign in to GitHub.com"
   - Введите ваш логин и пароль

3. **Добавьте проект:**
   - Нажмите **"File"** → **"Add Local Repository..."**
   - Нажмите **"Choose..."** и выберите папку с вашим проектом
   - Если появится сообщение "This directory does not appear to be a Git repository":
     - Нажмите **"create a repository"**
     - Name: `shkola-molitvy`
     - Local Path: (уже заполнено)
     - Initialize with README: ❌ (снимите галочку!)
     - Нажмите **"Create Repository"**

4. **Опубликуйте репозиторий:**
   - В правом верхнем углу нажмите **"Publish repository"**
   - Заполните:
     - Name: `shkola-molitvy`
     - Description: (уже заполнено)
     - Keep this code private: ❌ (СНИМИТЕ ГАЛОЧКУ!)
   - Нажмите **"Publish Repository"**

5. **Готово!** Код загружен на GitHub

#### Вариант B: Через командную строку (для продвинутых)

Откройте терминал (PowerShell на Windows или Terminal на Mac) в папке проекта:


### ШАГ 4: Включение GitHub Pages (5 минут)

1. Перейдите в ваш репозиторий на GitHub
2. Нажмите вкладку **"Settings"** (вверху, рядом с Insights)
3. В левом меню найдите **"Pages"**
4. В разделе **"Build and deployment"**:
   - **Source:** выберите **"Deploy from a branch"**
   - **Branch:** выберите **"main"**
   - **Folder:** выберите **"/ (root)"**
5. Нажмите **"Save"**

---

### ШАГ 5: Ожидание деплоя (2-3 минуты)

1. Перейдите во вкладку **"Actions"** в вашем репозитории
2. Вы увидите запущенный workflow "Deploy to GitHub Pages"
3. Дождитесь зелёной галочки ✅ (обычно 2-3 минуты)
4. Когда завершится, сайт будет доступен по адресу:
   ```
   https://USERNAME.github.io/shkola-molitvy/
   ```
   (замените USERNAME на ваш логин)

---

### ШАГ 6: Привязка домена shkola-molitvy.ru (15 минут)

#### 6.1: Добавьте домен в GitHub Pages

1. Вернитесь в **Settings → Pages**
2. В разделе **"Custom domain"** введите:
   ```
   shkola-molitvy.ru
   ```
3. Нажмите **"Save"**
4. GitHub покажет предупреждение — это нормально

#### 6.2: Настройте DNS у регистратора домена

**Где зарегистрирован ваш домен?**

##### Если на REG.RU:

1. Войдите на https://www.reg.ru/
2. Перейдите в **"Мои домены"** → выберите `shkola-molitvy.ru`
3. Нажмите **"DNS-серверы и управление зоной"**
4. Добавьте **4 A-записи**:

| Тип | Имя | Значение |
|-----|-----|----------|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |

5. Добавьте **CNAME запись**:

| Тип | Имя | Значение |
|-----|-----|----------|
| CNAME | www | USERNAME.github.io |

(замените USERNAME на ваш логин GitHub)

6. Нажмите **"Сохранить"**

##### Если на Beget:

1. Войдите в панель управления Beget
2. Перейдите в **"Управление доменами"** → выберите `shkola-molitvy.ru`
3. Нажмите **"DNS-серверы"** или **"Управление зоной"**
4. Добавьте те же записи, что и выше

##### Если на другом регистраторе:

Найдите раздел "DNS" или "Управление зоной" и добавьте те же записи.

#### 6.3: Включите HTTPS

1. Вернитесь в GitHub → **Settings → Pages**
2. Подождите 15-60 минут (иногда до 24 часов)
3. Когда появится **"DNS check successful"** ✅:
   - Поставьте галочку **"Enforce HTTPS"**
   - Нажмите **"Save"**

#### 6.4: Проверьте работу

Через 15-60 минут (иногда до 24 часов) сайт будет доступен:

```
https://shkola-molitvy.ru
```

## 📞 Если что-то не работает

### Проблема: Сайт не открывается на GitHub Pages

**Решение:**
1. Проверьте вкладку **"Actions"** — есть ли ошибки?
2. Убедитесь, что репозиторий **публичный**
3. Проверьте, что в Settings → Pages выбран branch **main**

### Проблема: Домен не работает

**Решение:**
1. Подождите до 24 часов (обновление DNS)
2. Проверьте DNS записи: https://dnschecker.org/
3. Убедитесь, что A-записи указывают на IP GitHub

### Проблема: Страницы не открываются при обновлении

**Решение:**
1. Убедитесь, что используется **HashRouter** (уже настроено)
2. Проверьте файл `public/CNAME` — там должен быть только домен
